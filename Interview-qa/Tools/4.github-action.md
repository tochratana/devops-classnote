**GitHub Action**

- What? : CI/CD tool របស់ GitHub។
- Why? : ងាយប្រើ ព្រោះវានៅជាមួយ GitHub repo ស្រាប់។
- When? : ពេល project នៅលើ GitHub ហើយចង់ build/test/deploy automatic។
- How? : 
 
បង្កើត file:

.github/workflows/ci.yml

Example:

name: CI
```jenkins
on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install
      - run: npm run build
```

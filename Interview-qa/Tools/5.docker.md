**Docker**

- What? : Docker ប្រើសម្រាប់ package application ជា container។
- Why? : ដើម្បីឲ្យ app run ដូចគ្នា លើ laptop, server, cloud។
- When? : ពេលចង់ deploy app ងាយៗ និងកាត់បន្ថយបញ្ហា “works on my machine”។
- How? : សរសេរ Dockerfile:

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
RUN npm install
RUN npm run build
CMD ["npm", "start"]
```
Build:

```sh
docker build -t my-app .
docker run -p 3000:3000 my-app
```

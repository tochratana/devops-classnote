**Jenkins**

> What?

Jenkins គឺជា CI/CD automation server។

> Why?

ដើម្បី build, test, scan, deploy project ដោយ automatic។

> When?

ពេលចង់ automate deployment។

> How?

សរសេរ Jenkinsfile:

```jenkins
pipeline {
  agent any

  stages {
    stage('Build') {
      steps {
        sh 'npm install'
        sh 'npm run build'
      }
    }
  }
}
```

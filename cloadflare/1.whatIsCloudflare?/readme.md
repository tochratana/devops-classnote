## Noted :

What is Cloudflare?

Cloudflare is a platform  that provide :
- CDN : (Content Delivery Network)
- DNS & Domain protection
- DDoS protection
- Speed & caching
- WAF (Web Application Firewall)
- Reverse Proxy
- Load Balancer
- Zero Trust/Tunnel

`Cloudflare sits between User ⇄ Your Server`
